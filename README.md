# CZL AI 桌面端

CZL Agent 的桌面客户端（Windows / macOS）：交给它一件事，它在你的电脑上自己做完。

本仓库只用于编译和发布安装包，客户端通过站点在线更新。

- 下载与安装说明：https://ai.czl.net/download ，或本仓库 [Releases](../../releases/latest)
- Windows：下载 `CZLAI-windows-amd64-installer.exe` 运行安装；首次运行若出现 SmartScreen 提示，点「更多信息」→「仍要运行」
- macOS：下载 `CZLAI-darwin-universal.dmg`，把 CZL AI 拖入「应用程序」；首次打开需在「系统设置 → 隐私与安全性」中点「仍要打开」
- 每个 Release 附带 `SHA256SUMS`，可用于校验下载文件
